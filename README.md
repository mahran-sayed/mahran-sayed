### 🔭 What I do

I work at the intersection of **aerospace** and **marine hydrodynamics**: turning CFD, simulation, and custom code into practical engineering answers.

- 🌊 **CFD & simulation**: geometry preparation, high-quality structured/unstructured meshing, multiphase flow for hull resistance, rotating-arm (angular drag) tests, DEM simulations, post-processing and data analysis
- 🚤 **Underwater vehicles**: complete drag matrix (Fossen's model) for RSV2 in its different operating modes, hydrofoils, conceptual-stage hand calculations
- ⚙️ **Propulsion**: thruster selection, design, CAD modelling and simulation; contributed to MCS's in-house thruster code (CAD generation for AU, Kaplan and B-series propellers)
- 🚢 **Seakeeping**: RAO calculations for surface vessels
- 🛠️ **Custom engineering tools**: web apps and scripts that automate meshing, setup and post-processing workflows
- 🤖 **Obsessed with automation and scripting**: if I have to do it twice, I write a script for it
- 🚀 **Aerospace**: aerodynamics, structures and design, with OpenRocket and XFOIL for rockets and airfoils
